# D&G Decorações — Landing Page

Landing page desenvolvida para apresentação profissional da D&G Decorações.

## ✨ Sobre o projeto

O projeto foi criado com foco em:
- experiência visual premium
- responsividade total
- apresentação elegante do portfólio
- performance e carregamento rápido
- identidade visual sofisticada
- integração direta com WhatsApp

A proposta do site é transmitir profissionalismo e destacar o impacto visual das decorações através de uma experiência moderna.

## 🚀 Tecnologias utilizadas

- Next.js
- React
- TypeScript
- TailwindCSS
- Vercel

## 🎨 Recursos implementados

- Layout responsivo
- Galeria premium de imagens
- Ajuste individual de posicionamento das fotos
- Hover animations
- Seções animadas
- CTA para WhatsApp
- Design mobile-first
- Otimização visual para eventos e decoração

## 🌐 Projeto online

🔗 https://landing-page-dg.vercel.app

Landing page desenvolvida para fortalecer a presença digital da D&G Decorações e valorizar visualmente seus eventos e serviços.
